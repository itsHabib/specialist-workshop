# Where should an importer spend its next verification call?

Each synthetic arrival contains eight feeds split across two channels. Every feed uses either day/month/year or month/day/year consistently. If exactly one interpretation parses all rows, the importer resolves the feed for free. Otherwise it follows the supplied hint. Two valid parses can produce different ISO dates. A paid lookup supplies the trusted ISO date for one wire record, which can resolve the rest of that feed. Only the selected feed may be changed. A lookup can inform later selections in the same batch.

## Questions and controls frozen for this run

1. With **two** paid lookups per eight-feed batch, how many more exact dates does an empirical ranker recover if it updates after each lookup? Compare adaptive and fixed orders on the same batches, separately for correlated and independent hints. Report mean additional exact rows per batch, wins, ties, losses and a descriptive paired 95% percentile interval from 2,000 batch resamples with seed 713. Variation across dates within the same feed does not contribute independent samples.
2. Do a fitted tree or a fine-tuned Google BERT ranker outperform empirical rates, a largest-ambiguous-feed rule, or the native import? Compare budgets of one, two and three calls on every held-out batch. Publish wrong dates remaining and the hindsight ceiling obtained by spending the same number of calls on the largest realized gains.
3. Does explicitly planning future calls help? Compare greedy empirical selection with a finite-horizon empirical planner. The planner branches on a purchased witness confirming or contradicting the hint and considers how each branch changes the next decision. It uses the fitted outcome probabilities at planning time. The hindsight ceiling uses actual outcomes only for grading and its labeled control.

## Cohorts and training

Use 96 independent coupled training batches, 32 coupled development batches and 128 held-out batches split evenly between coupled and independent channels. In the coupled regime a channel shares a hidden switch, with an independent 12% flip on each feed. In the independent regime each feed draws a fresh switch. The migration notice changes the switch probability from 0.25 to 0.70 in either regime. This preserves the theoretical single-feed probabilities while changing how much can be learned from another feed. Hints, identifiers and dates are synthetic. The shifted regime never appears in fitting or development.

Give each ranker the channel notice and a category summarizing observable same-channel evidence (unseen, right, wrong or mixed). First use free facts from feeds with a unique valid interpretation. Generate fit examples at zero, one and two additional paid peer observations when available. Exclude the target feed from its history. The label is whether buying its witness would increase exact rows. Use identical task and row bytes for both learned scorers, one depth-four tree with a minimum of four rows per leaf and one Google BERT-Tiny fine-tune with four epochs, batch size 16 and seed 17. No hyperparameter or policy selection uses either evaluation split. The empirical scorer estimates the positive rate for each state using add-one smoothing, then falls back to the notice group and global counts for missing states.

All scored policies multiply the estimated probability of a wrong hint by the number of rows that differ between the two available parses. Fixed ranking retains the initial free evidence for all calls. Adaptive ranking incorporates only facts the importer has already paid to see. Every budgeted arm spends up to the same number of lookups, limited by the number of unresolved feeds. The no-lookup control spends zero. Use source order for exact ties, with a tolerance of 1e-10 for numerically equivalent lookahead values. A correct source ISO date is visible only in a purchased witness or to the grader.

Log the ordered paid selections, realized hint correctness and gain, total exact rows, and errors remaining on every batch. Include every arrival. Check input disjointness by IDs and payload, and independently recompute the grades from actual date parses. The results describe a bounded simulator where one trusted example identifies a whole feed's convention. They do not measure calendar ambiguity or error frequencies in external systems.
