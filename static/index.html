THE PLATFORM UNDERNEATH

OpenAPI schema ↗

Call a skill

Start the app locally, then send text to the inference endpoint. Select a completed checkpoint to use the specialist.

GET/api/skillsDiscover available skills
POST/api/skillsImport your own task and datasets
POST/api/inferRun base, specialist, or reference inference
POST/api/skills/{id}/correctionsAdd or replace a practice example
POST/api/runsStart training or evaluation
GET/api/runs/{id}Read progress, metrics, and results

Connect a reference model

Set an OpenAI-compatible chat-completions endpoint on the server. Choosing “Reference provider” explicitly sends the selected input to that provider. Credentials stay on the server. 

WORKSHOP_REFERENCE_URL=https://your-provider.example/v1
WORKSHOP_REFERENCE_MODEL=your-model-id
WORKSHOP_REFERENCE_KEY=your-key

Reference results are labeled with the configured model. There are no simulated frontier scores or automatic remote fallbacks. This is a single-user localhost POC, not a hosted multi-tenant service.
